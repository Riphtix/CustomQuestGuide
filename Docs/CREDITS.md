# Credits and data sources

Custom Quest Guide is built for the Dalamud plugin ecosystem and uses FFXIV game data plus optional community data to provide acquisition guidance.

## Runtime / development ecosystem
- Dalamud
- Lumina
- FFXIVClientStructs
- LuminaSupplemental.Excel

## Optional community acquisition data
- FFXIV Collect
- Garland Tools

CQG treats live game data as primary whenever practical and uses community data as supplemental/fallback enrichment. Community services remain the property of their respective maintainers and may have their own terms, licenses, and availability policies.

FINAL FANTASY XIV and related game data/content are property of Square Enix. Custom Quest Guide is an unofficial third-party plugin and is not affiliated with or endorsed by Square Enix.

- FFXIV Todo (datamachine) — MIT-licensed generated content index used as an optional duty-unlock fallback.
